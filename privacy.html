Informativa sulla privacy

Ultimo aggiornamento: 9 novembre 2026

ex-press è uno strumento personale e non commerciale usato esclusivamente dal titolare del canale YouTube ex-press (@ex-press-tube) per pubblicare i propri video. Non è offerto ad altre persone.

Dati a cui accede

Con l'autorizzazione concessa dal titolare tramite Google (OAuth), ex-press usa l'API YouTube Data v3 con due autorizzazioni:

  • youtube.upload: caricare i video sul canale e impostarne la miniatura;
  • youtube.readonly: leggere il nome del canale e l'elenco dei video caricati.

Non accede a email, contatti, file o altri dati dell'account Google.

Come vengono usati i dati

Solo per caricare i video del canale ex-press e controllare che il collegamento funzioni. I dati non vengono venduti, condivisi con terzi, usati per pubblicità né per addestrare modelli di intelligenza artificiale.

L'uso e il trasferimento ad altre app delle informazioni ricevute dalle API di Google rispettano le Norme sui dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato.

Conservazione

Il token di accesso rilasciato da Google è salvato solo sul computer del titolare. ex-press non ha server e non raccoglie dati di altre persone.

Revoca e cancellazione

L'accesso può essere revocato in qualsiasi momento dalla pagina Autorizzazioni dell'account Google. Eliminando lo strumento dal computer viene cancellato anche il token.

Servizi di terze parti

ex-press utilizza i Servizi API di YouTube: valgono i Termini di servizio di YouTube e le Norme sulla privacy di Google.

Contatti

English summary

ex-press is a personal tool used only by the owner of the ex-press YouTube channel. With the owner's OAuth consent it uses the YouTube Data API scopes youtube.upload (upload videos and set thumbnails) and youtube.readonly (read the channel name and uploaded videos), solely to publish the channel's own videos. The access token is stored only on the owner's computer; no data is sold, shared, used for advertising or for AI training, and there are no servers. ex-press's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. By using YouTube API Services the YouTube Terms of Service and the Google Privacy Policy apply.
